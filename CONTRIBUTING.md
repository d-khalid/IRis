# Contributing

This project facilitates contributors but requires strict guidelines to be followed in an effort to diminish low-quality contributions. With regards to this, documentation-related changes are not accepted from contributors because they are considered low-effort. 

For further details, have a read bellow:

---

## Use of AI Agents

IDE-integrated AI agents are allowed to be used only under `ask` mode. You have to make the changes manually. We believe doing so forces contributors to think before adding/removing/changing code. See [why do we have a AGENTS.md file](https://github.com/d-khalid/IRis#why-do-we-have-a-agentsmd-file) section in `README` for more details.

---

## Issue/PR Templates

These keep every issue/PR in structure and serve as guidance. But do keep in mind that these are not hardcoded rules to blindly follow. It is perfectly fine to backspace the template structure and draft your issue/PR in a blank one.

---

## Contribution Process

Simply follow these steps:

- Pick any issue from the issues section. 
- Comment in the issue, discuss the solution, and get it approved by a maintainer.
- You do not need to type in descriptions for pull requests. Since you've already discussed on the topic just link the issue number and it will be accepted.
